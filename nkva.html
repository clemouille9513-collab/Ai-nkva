🤖 Vraie IA (modèle de langage local)

Active un vrai modèle de langage qui tourne dans ton navigateur : pas d’API, pas de serveur. Il comprend n’importe quelle phrase, répond à tout, écrit et corrige du code. Une fois téléchargé, il marche hors ligne.

Téléchargement unique (≈ 1 à 2,5 Go) : fais-le en Wi-Fi. Il faut un navigateur avec WebGPU (Chrome récent sur PC ou Android).

        ⚡ Option rapide : IA native sur ton téléphone (Termux)
        
Bien plus rapide et fiable que dans le navigateur : Termux fait tourner le modèle, NKVA s’y connecte. Aucune API externe, tout reste sur ton téléphone.

        
pkg install -y clang wget cmake git
git clone https://github.com/ggerganov/llama.cpp
cd llama.cpp
cmake -B build && cmake --build build --config Release
wget https://huggingface.co/bartowski/Qwen2.5-1.5B-Instruct-GGUF/resolve/main/Qwen2.5-1.5B-Instruct-Q4_K_M.gguf
./build/bin/llama-server -m Qwen2.5-1.5B-Instruct-Q4_K_M.gguf -c 4096

        
La compilation dure un moment. Laisse Termux ouvert (réduit) : le serveur écoute sur le port 8080. Si la compilation échoue sur « spawn.h », fais : pkg install libandroid-spawn

ℹ️ À propos de NKVA v2

      

        Comment ça marche
        
    
          
  • Tout tourne dans cette page : aucune API, aucun serveur, aucun envoi de données.
    • 
          
  • Les photos sont analysées sur ton appareil (canvas) et ne quittent jamais la page.
    • 
          
  • NKVA comprend par mots-clés, ressemblance de phrases (TF-IDF) et fautes de frappe tolérées.
    • 
          
  • Il apprend ce que tu lui enseignes et le garde dans ton navigateur.
    • 
        

      

      

        Ce qu’il sait faire en code
        
    
          
  • Générer des projets complets : snake, morpion, pong, calculatrice, to-do, chrono, dessin…
    • 
          
  • Analyser du code HTML / CSS / JS / Python / JSON : erreurs de syntaxe, balises non fermées, fautes de frappe CSS, mauvaises pratiques.
    • 
          
  • Exécuter HTML, CSS et JavaScript dans un bac à sable avec console.
    • 
          
  • Formater, minifier, expliquer du code et décoder des messages d’erreur courants.
    • 
          
  • Répondre à ~60 questions de programmation (variables, async, flexbox, git, SQL…).
    • 
        

      

      

        Ce qu’il ne fait pas
        
NKVA n’est pas un grand modèle de langage : il n’invente pas de réponses sur des sujets qu’il ne connaît pas, et sa « vision » est une analyse de pixels (couleurs, luminosité, netteté, formes), pas une vraie reconnaissance d’objets. Plus tu lui apprends de choses, plus il progresse.
